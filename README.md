# Foodex 🍔🚚

## Descripción

Foodex es una página web de delivery desarrollada como proyecto académico para el curso de Diseño y Desarrollo de Software en CERTUS.

La plataforma permite a los usuarios visualizar promociones de restaurantes, explorar diferentes opciones de comida rápida y acceder a información relacionada con los servicios ofrecidos. El proyecto fue desarrollado con el objetivo de aplicar y reforzar conocimientos fundamentales de desarrollo web utilizando HTML, CSS y JavaScript.

---

## Objetivos del Proyecto

* Aplicar conceptos básicos de desarrollo web.
* Aprender el uso de HTML5 para la estructura de páginas web.
* Implementar estilos visuales mediante CSS3.
* Incorporar interactividad utilizando JavaScript.
* Desarrollar una primera aplicación web funcional en equipo.
* Fortalecer habilidades de trabajo colaborativo y gestión de proyectos.

## Funcionalidades

* Página de inicio atractiva e interactiva.
